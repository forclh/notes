# 异常处理

## 异常的捕获

使用 `try...except` 捕获可能发生的异常：

```python
try:
    number = int("abc")
except ValueError as e:
    print(f"数值错误: {e}")
except TypeError as e:
    print(f"类型错误: {e}")
else:
    print("没有异常时执行")
finally:
    print("始终会执行")
```

可以捕获多个异常，并获取异常对象：

```python
try:
    number = int("abc")
except ValueError as e:
    print(e.args)  # 获取异常信息
    print(e.__traceback__)  # 异常的堆栈跟踪对象
```

**要点：**

- `try` 中放可能出错的代码
- `except` 捕获指定类型的异常，`as e` 拿到异常对象
- `else` 在没有异常时执行
- `finally` 无论是否有异常都执行（常用于释放资源）

## 异常类型

Python 内置异常形成层次结构，捕获父类异常可以捕获其所有子类：

```
BaseException
 ├── SystemExit          # sys.exit() 引发
 ├── KeyboardInterrupt   # Ctrl+C 引发
 └── Exception           # 常规异常的基类
      ├── ArithmeticError
      │    └── ZeroDivisionError
      ├── LookupError
      │    ├── IndexError
      │    └── KeyError
      ├── TypeError
      ├── ValueError
      │    └── UnicodeError
      └── ...
```

```python
# 捕获 Exception 可以捕获几乎所有常规异常
try:
    # 可能引发各种异常的操作
    pass
except Exception as e:
    print(f"发生错误: {e}")

# 但不推荐捕获过于宽泛的异常，应尽量精确
```

**最佳实践：** 尽量捕获精确的异常类型，避免裸 `except:` 或滥用 `except Exception`，否则会掩盖真正的 bug。

## 主动抛出异常

使用 `raise` 主动抛出异常：

```python
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("余额不足")
    if amount <= 0:
        raise ValueError("取款金额必须大于零")
    return balance - amount


try:
    withdraw(100, 200)
except ValueError as e:
    print(e)  # 余额不足
```

可以重新抛出当前异常：

```python
try:
    risky_operation()
except Exception:
    # 记录日志后继续抛出
    print("发生异常，准备抛出")
    raise  # 重新抛出
```

> `raise` 不带参数时，会重新抛出当前正在处理的异常。

## 自定义异常

通过继承 `Exception` 或其子类创建自定义异常：

```python
class ValidationError(Exception):
    """参数验证失败"""
    pass


class NotFoundError(Exception):
    """资源不存在"""

    def __init__(self, resource, resource_id):
        self.resource = resource
        self.resource_id = resource_id
        super().__init__(f"{resource} (id={resource_id}) 不存在")


def get_user(user_id):
    if user_id <= 0:
        raise ValidationError("用户ID必须大于零")
    if user_id not in user_database:
        raise NotFoundError("User", user_id)
    return user_database[user_id]
```

**要点：** 自定义异常让调用方可以按业务语义精确捕获，异常对象上还可以携带额外的上下文信息（如 `resource_id`）。

## 异常链

```python
def exception_chains1():
    # 方式1：直接抛出（无关联）
    try:
        raise ValueError("错误A")
    except ValueError:
        # 这里可以做一些其他处理。
        raise RuntimeError("错误B")  # 隐式关联，__context__ 有值


def exception_chains2():
    # 方式2：from 显式关联
    try:
        raise ValueError("错误A")
    except ValueError as e:
        # 做了一些其他处理。
        raise RuntimeError("错误B") from e  # 显式关联，__cause__ 有值


# 查看区别
try:
    exception_chains1()
except RuntimeError as e:
    print("隐式关联:", e)
    print(f"  __cause__: {e.__cause__}")  # None
    print(f"  __context__: {e.__context__}")  # ValueError

try:
    exception_chains2()
except RuntimeError as e:
    print("\n显式关联:", e)
    print(f"  __cause__: {e.__cause__}")  # ValueError
    print(f"  __context__: {e.__context__}")  # ValueError
```

**要点：**

- 在 `except` 块中直接 `raise` 新异常，会**隐式关联**：`__context__` 保存原始异常，回溯信息中显示 "During handling of the above exception, another exception occurred"
- 使用 `raise 新异常 from 原异常`，会**显式关联**：`__cause__` 保存原始异常，回溯信息中显示 "The above exception was the direct cause of the following exception"
