# Notes

个人学习笔记仓库。笔记用 Obsidian 语法编写，通过 Quartz 构建为静态网站，push 后由 Cloudflare 自动构建发布。

## 专题约定

每个顶层文件夹代表一个专题（如 `Python语言核心精讲/`），约定如下：

- **章节笔记**：`NN-章节名.md`，直接放在专题目录下，文件名含章节号与主题，便于 Obsidian 搜索 / 标签页 / 反向链接识别。
- **作业源文件**：统一放在专题的 `homework/` 文件夹；命名加章节前缀（如 `03-p1.py`、`13-p5.py`），避免 Obsidian 嵌入链接冲突，也便于全局查找。
- **嵌入**：在章节笔记的 `## 参考答案` 段使用 `![[NN-pN.py]]` 嵌入，Obsidian 阅读视图会按 basename 解析并直接渲染代码，无需关心 .py 实际所在子目录；同步脚本会将其转为网站上的高亮代码块。
- **frontmatter**：每篇笔记带 `chapter / title / tags`；`permalink` 短码由同步脚本在首次发布时自动分配并固定，不要手改。
- **目录页（MOC）**：`00-` 开头的索引页，作为专题导航，同时也是网站首页的正文来源。

## 发布流程

1. 在专题目录下写笔记；
2. 在 `site/` 目录运行 `node sync-content.mjs` 同步生成站点内容（分配短码、转换嵌入、重写双链、生成首页）；
3. commit 并 push，Cloudflare 自动构建发布。

详细的仓库结构与术语见 `CONTEXT.md`。
