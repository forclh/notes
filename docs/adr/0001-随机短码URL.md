# 随机短码 URL

笔记站每篇笔记的 URL 需要英文短链接，但文件名全是中文，语义化的拼音 slug 既长又需要持续维护。我们决定：每篇笔记在首次发布时被分配一个 6 位随机 base62 短码，写入笔记 frontmatter 并永久固定；专题层保留一个人类可读的英文短名（如 `/python/x7Kq2m`），使文件树组件仍按专题分组可导航。URL 一旦发布即视为永久承诺，不再随文件改名而变化。

## Considered Options

- 语义化拼音 slug（标题转拼音）：无需维护映射，但 URL 长、对非中文读者仍是乱码。
- 集中映射文件：不改动笔记，但与笔记分离、需额外同步。
- 全扁平随机码：URL 最短，但左侧文件树退化为随机码列表，无法导航（已否决）。
